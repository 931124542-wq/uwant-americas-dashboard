# 线上研究界面更新 · 2026-11-02

本次从已验收的本地开发版本 `39b1e44` 提取运行界面及公开产品研究目录，更新现有GitHub Pages网址。第五阶段的竞争力分析草稿尚未完成，没有随本次发布。

## 数据范围

- 品牌分析、产品研究、来源详情与多商品配置比较共用研究目录；可见性与销量统计资格分开。
- 原有国家、渠道、月份及产品类型筛选保留。价格带沿用各国本币分档；商品数量不代表销量或市场份额。
- 产品及型号来自已有公开商品页、品牌资料与已有配置档案；每件保留来源、日期及版本限制。
- 加拿大3909B仍作为待核竞品可见，但私有试采的月度数值和详情观察价格未公开，也不参与统计。详细的私有审查附件保留在本地。
- 本地MCP新增的220条来源记录、210条月度期末价、较新10月版本及恢复资格结果均未打包到公共站点。线上页面仅使用原有生产数据，不能把本地采集成果误称为线上已接入。
- 卖家精灵企业/多人共享许可尚未核清；本次未增加受限原始响应、计费账本、凭证或私有暂存数据。
- 没有新增付费MCP查询，没有改写原生产历史文件，没有将缺失值补为零。

## 页面变化

品牌页用品牌布局表呈现产品覆盖、配置标称、同口径价格和具备资格的样本统计，支持钻取商品。商品页保留图片、Amazon链接、来源及配置比较；没有报价或销量时显示具体缺项。AW、Pa、kPa和W保留原单位，不作跨单位优劣评分。

公开版的覆盖数及可统计结果可能少于个人本地预览，这是数据授权范围的差异，不能通过借用其他期间、国家或平台填补。

发布前补充修复：非Amazon渠道及未纳入双市场目录的国家仍保留完整筛选上下文，避免品牌页因缺少scope而报错。
