# Amazon大盘统一与研究资料补充

用户于2026-11-11授权将本轮补充更新到网站，并让Amazon市场大盘采用Mercado Libre的展示方式。

两平台保留相同的四个模块、四张主指标卡、UWANT双份额、品牌环图、价格带图、商品研究及明细导出。Amazon主指标与品牌/价带图均使用同一国家、品类、币种、月份和产品类型下的合格历史父体月份；销量与金额各自核验。期末标价中位数只取所选结束月的单一有效报价父体，缺价不补零，不用当前价回填。原类目报告移到折叠来源参考，其原统计数据和期间保持原样。Mercado仍采用原批次近30天快照，未转换成自然月。

本轮公开7个商品的规范化资料补丁，包括5个商品本次取得的五点配置、1个巴西WAP档案补充，以及1个旧缓存空配置补全。补充3张来源图片，保留原图片采集日和型号未独立认证状态。WAP厂家同名型号参考区分尘杯总容量360mL与可用160mL，不认证某个ASIN的SKU、套装或在售状态。

发布52个新增商品月份来源观测：MX Tineco S6 Master 7个月（2026-04—2026-10）、CA JIMMY JV35 24个月（2024-11—2026-10）、US FEPPO 21个月（2025-02—2026-10）。所有新增来源销量和金额保持不可合计，父体归属为空；JV35同日两个父体事件原样保留。没有新增Listing或已核型号，没有改变已有4938行正式历史、ML 6207条档案及613个商品历史。

仅发布规范化商品字段、配置标称、公开图片URL和明确隔离的历史观测。新原始响应、完整五点原文、扣费/余额、请求ID、内部经营资料、个人路径和密钥不进入发布包。脚本`scripts/publish-research-supplement.py`按外层白名单执行增量更新，同批次重复构建不重复添加记录。

验证包含32个国家/品类/统计指标组合的分母核对、严格类型筛选、结束月报价、源历史逐字一致、52个月份隔离、图片证据、同日父体冲突、发布隐私边界，以及实际浏览器的双平台主指标、品牌和价带明细、CSV、月份修改/刷新、手机布局和新增资料。全站288场景通过。测试证据留在仓库外研究目录。
