# Amazon 各国市场大盘展示一致性修复

本次以加拿大页面为参照，检查墨西哥、加拿大、美国、巴西四个 Amazon 站点的四个品类。研究目录、原始历史记录、统计资格及各国币种均未改变。

原问题：没有合格月度销量/销售额时，四张主卡会从销售指标切换为商品数、品牌数、图片数及历史档案数；品牌和价格带区域又自动插入按 Listing 数量绘制的目录图。同一个市场总览入口在不同国家出现不同指标语义，容易把目录覆盖当作销售结构。

修复后所有站点始终保留加拿大的四项主指标及顺序：样本销售额、样本销量、结束月标价中位数、合格历史父体样本。缺失金额/销量为“—”并写明所选期间暂无可合计值，不转为 0。合格父体数为真实通过核验的样本数量，0 不代表当地市场为 0。

品牌竞争格局、价格带分布始终保留两个图表位置。缺销售事实时显示空状态，不画虚假环图，不用商品数替代销量或销售额。无可导出月度事实时禁用份额明细导出；真实 0 值事实仍可导出。商品资料覆盖改为统一的折叠入口，商品和报价仍能下钻查询。

原类目报告保留原国家、币种、范围和统计期间。有独立报告但缺合格月度样本的范围提供直接查看入口；它不回填主卡、不进入月度份额或增长率。比如墨西哥吸尘器原类目报告 2026-09-29—2026-10-28 的来源销售额 10,200,593.41 MXN，不填入 1—9 月自然月样本。原类目报告未按同类型直接竞品清洗，仍明确标注为来源参考。

验证：15项 Node 数据/展示/隐私契约套件及8项 Python校验通过。新增96种国家×品类×指标×期间组合检查；真实 Chrome 核对四站四品类、加拿大原值、品牌/价格带下钻、CSV、月份/指标/产品类型、刷新/前进/后退及四国手机页面。另通过原有缺失值、Amazon/美客多共用市场展示、导航及经营入口的浏览器回归。新检查已加入现有 Pages 发布校验流程；截图和下载验证文件保存在仓库外。
