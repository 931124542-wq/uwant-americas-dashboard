# 大促时间点 · 11.17.3

此前促销日历默认筛选“接下来的活动”，已结束的大促不在列表中；新导入的活动订单仅接入经营总览、分析和SKU页，与促销日历缺少入口关联。

现在日历默认查看全年，首屏以“重点大促时间点”直接展示当前国家、年份及筛选范围内的活动起止日期。所有日期沿用已有日历来源，待公布或冲突日期不进入时间线。月份、渠道、活动类型、日期状态和搜索仍共同作用，明细与CSV保持原始日期。

墨西哥Buen Fin原日历活动期为2026年11月13—17日；本轮再次核对[主办方官方问答](https://www.elbuenfin.org/preguntas-frecuentes/)及[SAT活动页面](https://www.sat.gob.mx/minisitio/SorteoElBuenFin/)。这与用户报表覆盖日期是两个范围，不能将报表最后一天当作全活动结束日期。

已导入的活动报表在日历上方显示自己的开始/截至日期、每天非取消订单及各渠道原标注截数时间。日历活动卡同时标明报表未覆盖的活动日期，不填零、不推算；点击每日日期进入经营总览并筛选当天订单，“查看全期订单”恢复完整报表。经营总览也增加报表期间与“大促时间点”入口。没有导入报表的日历直接显示公开活动安排，不占用首屏展示报表导入和空数据说明。

报表仍仅存于当前浏览器，不发布个人订单或新经营数字。原日历、市场、历史销量与库存数据未改动。经营iframe使用日历专用构建参数，仅替换calendar.js与calendar.css，其余原模块的打包内容保持不变。公开回归使用合成报表；用户报表的核对、导出和截图仅保存在仓库外。

检查覆盖：原日历链接、已结束活动可见性、活动与报表日期区别、月份/渠道/搜索/日期状态、导出、每日下钻、全期恢复、刷新、手机宽度、历史销量与库存保留，以及无报表时的公共日期显示。
