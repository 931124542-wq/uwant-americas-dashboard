# Amazon 与 Mercado Libre 共用总览及旧链接修复

复现用户原链接：美国、布艺清洗机、`dataset=curated`、Y100S、销量占比，以及遗留的 MXN 美客多价格带。线上当时已加载 `2026-11-12-amazon-country-consistency`，但此档案入口仍无自然月选择；Amazon 和美客多仍经不同结构渲染。上一轮测试主要覆盖自然月入口，未覆盖这个完整旧链接。

本次新增 `market-overview-layout.js`。两平台均挂载同一个模板 `shared-market-2026-11-12`：市场大盘、品牌与价格带、UWANT对标、经营判断。主卡、速览、观察控制、图表、重点商品和对标使用固定插槽。保留原数据引擎、原图表事件和明细导出；模板不修改商品、销量、金额或统计资格。Amazon 原档案说明、类目来源、原趋势等收入折叠来源区，移除重复对标面板；月度选区仍可使用。

旧市场总览链接的 `curated/focus/archive` 进入本看板既有默认自然月 `2026-09`，不再停留在“请选择月度历史期间”。已有有效起止月份保持原样；商品研究的原档案入口保持不变。Amazon 删除仅供美客多使用的价格带参数，国家、品类、UWANT型号及销量/金额选择保留。两平台的首个时间入口统一称“市场概览”，顶部实际期间仍分别标自然月或近30天，未将两种数据混为一体。

重点商品在有合格销售事实时使用去重历史父体或Listing估算；Amazon 跨月份按历史父体与当时品牌分组，代表ASIN不取得子体销量。在没有合格销量时仍显示已收录同类型商品资料，明确不作销量排名；销量/销售额留空，报价保留各自日期。普通压力蒸汽清洁器等不符合便携布艺形态的资料不进入此重点参考区。原有隔离、缺失和统计分母保持不变。

美国布艺机当前仍没有可合计的合格自然月销量和金额，图表明确保留缺口；此次修复没有用资料数量、待核销量或现价反算金额。加拿大1—9月吸尘器样本仍为38,405台、5,330,501.66 CAD；美客多近30天快照也未变。没有新增采集、发布私有响应或改写原历史。

页脚显示“市场版 11.12.3”，静态资源采用内容哈希更新。

验证：16项Node数据/隐私/展示套件、8项Python校验通过；48个旧档案入口转换及原链接参数保持、历史父体不混算、真实0值/缺失等契约通过。实际Chrome从用户完整旧链接进入，核对两平台相同模板插槽、四国四品类、研究入口、品牌/价格带明细、CSV、月度区间/刷新、桌面/手机。另通过Amazon四国一致性、市场展示、出货与经营联动回归。测试截图与下载证据保留在仓库外。
