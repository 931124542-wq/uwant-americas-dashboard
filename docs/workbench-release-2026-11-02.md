# 产品库与市场工作台公开更新 · 2026-11-02

原线上版本为 `80ba63c`。本次发布包含本地 `75e9a79`、`e7cf0c3`、`2d81fb7`、`8eec8bf` 四轮已完成的界面与交互修改，保留现有GitHub Pages网址，继续使用表格为主的布局。

## 上线内容

- 市场概览、商品研究、品牌分析、UWANT对比共用国家、渠道、品类、月份上下文；选定型号在页面顶部展示。研究候选与正式统计分开。
- 四品类分别设置对比字段，直接用途竞品、相邻替代和待核关系分别显示；来源和关键配置可展开。
- 商品目录独立于单月销量是否存在，保留型号组、当地版本和平台Listing；旧标题含Bonus Accessories不再导致整机被当作配件。桶式、商用、机器人及替换耗材的排除继续执行。
- 新增公开商品及图片证据，来源日期、促销、缺货和版本限制分别保留。图片1×1或访问失败明确显示缺失，不用相近型号替代。有效尺寸不等于型号/地区版本已逐图核实。
- 支持2026年起止月份选择、逐月覆盖、商品历史和CSV；只有合格且逐月去重的样本参加区间销量/销售额合计，缺月不补零。价格只按结束月及原口径展示，不跨月相加或冒充成交均价。
- 整列缺失的销量、金额、价格或配置集中说明；没有有效数值的历史表默认紧凑呈现，仍可展开档案状态。相同采集日期和归属说明只显示一次。
- 旧来源卡片也执行既有统计资格检查，待核原值不影响正式销量排序或品牌合计；原值在详情及CSV中明确标注。
- 经营、库存、利润、任务、日历、数据导入导出和访问设置保留。历史经营记录缺失的流量/广告列集中说明；手机保留局部表格滚动并修正分页按钮。
