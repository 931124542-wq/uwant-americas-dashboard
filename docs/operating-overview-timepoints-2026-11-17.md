# 经营总览首屏大促时间点 · 11.17.4

此前完整的大促时间卡只放在促销日历。经营总览还要求当前浏览器已载入活动报表，并受用户上次选择的历史实销或原经营报表影响。这导致用户直接打开经营总览时看不到所需时间点。

现在墨西哥经营总览首屏固定展示Buen Fin大促时间卡和每天日期，未导入报表也显示活动开始、期间和结束。日期来自原公开促销日历，通过生成脚本提取，自动化校验确保两处一致。公开日期档案不含订单、销量、金额或个人资料。

已经载入活动报表时，每日日期直接显示非取消订单台数和各渠道原报表截数时间。活动中未被报表覆盖的日期显示“报表未覆盖”；未载入报表与已覆盖的真实零分别处理。切换历史实销或原经营报表不会隐藏时间卡，点击可用日期会在经营总览内筛选该日订单，不跳转日历。摘要按报表全期，明细按选中日期，两者分别标明。

不改动原市场资料、原日历日期、历史实销、库存和活动订单。原报表仍保留自身统计期间。个人报表仍通过用户浏览器载入，不写入公开发布包。当前浏览器没有报表时明确说明，并提供载入入口。

新增回归覆盖用户经营总览链接、无导入首屏、历史/原报表模式、刷新、日期下钻不离开总览、载入按钮、手机首屏及国家隔离。真实报表核对结果与截图在公开仓库之外保存。
