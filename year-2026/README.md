# 2026 年产品历史数据

来源：卖家精灵 MCP `asin.sales.trend`。采集日期：2026-10-28。

466 个站点商品全部查询成功：美国201、加拿大142、墨西哥109、巴西14。取得3,518条有指标的商品月度记录，3,440条有父体月销量。另保留缺失及未来月份的状态行，共5,592行。

范围为当前看板已收录的美国、加拿大、墨西哥和巴西商品，按“站点＋ASIN”回查 2026 年历史。当前未收录、年内已退市的商品不在这个名单内，不能据此推算全年完整市场规模。

- `2026-monthly.csv` / Excel 月度明细：每个站点、ASIN、月份一行，保留原始指标和空值。11—12月标记为尚未发生，不填销量。
- `product-coverage.csv`：每件商品的查询状态、收录月份及失败原因。
- `parent-changes.csv`：接口返回的父体变更，不代表已覆盖全部历史关系。
- `recent-30-days.csv`：接口随月度查询附带的近30天逐日估算，单独保存，没有合并到自然月销量中。
- `validation.json`：查询数量、各国逐月覆盖、缺失及校验结果。

## 指标

| 字段 | 含义 |
|---|---|
| parentSales | 父体月销量估算。不能把同一父体下多个子体的该值直接相加 |
| parentSalesAmount | 对应父体月销售额，按站点原币种保留 |
| childSales | Amazon 搜索页“过去一个月购买量”的子体月度快照，与父体估算不是同一指标 |
| childSalesAmount | 对应子体销售额 |
| price | 当月最后一个有效价格点，不是月均价 |
| bsr / rating / reviews | 当月最后一个有效日的排名、评分及评价数，不是整月平均或新增数 |

10月仍未结束，接口返回的10月数值只作为未结月快照，不称作已结算整月或截至采集日的实际成交累计。早期月份没有记录，可能是尚未收录，不能解释为当时没有销量。

看板品牌和商品分类来自当前档案。父体优先使用历史变更记录；未返回历史关系时，沿用当前档案并标明依据。当前档案父体仅供参考；工作台只将历史关系已确认且数值一致的父体纳入已知样本合计，其余保留待核；完整原始 ASIN 月度记录在明细中保留，历史关系缺失仍可能影响样本合计。

接口中同一天存在多个父体且没有先后时间的情况，影响1,356个商品月份的关系判断，已逐行标记并保留当前档案作为参考。另有1件墨西哥商品标题与详情品牌冲突，仍列为品牌待核，保留详情原品牌。原始销量没有因为这些问题被改写。

验收：160组国家、品类、月份组合通过筛选、去重、品牌合计、价格带、深链接及导出检查；原有264组归档/历史筛选与64组品牌/品类检查通过。浏览器验证了1月与10月切换、期末价标题、返回和CSV下载；Excel已检查三个工作表、筛选表、冻结行列、空值与源数值。

美国为 USD，加拿大 CAD，墨西哥 MXN，巴西 BRL。没有跨币种相加，也没有用价格乘销量替代缺失的销售额。
